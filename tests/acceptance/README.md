# Tests d'acceptation

Les tests de ce dossier vérifient des critères des besoins par profil, par les points d'entrée publics. Chaque test porte l'identifiant `AT-<besoin>-<n>` dans sa docstring.

La liste complète, avec le statut de chaque critère, est dans le wiki : [`openwiki/fr/tests/acceptance-tests.md`](../../openwiki/fr/tests/acceptance-tests.md). Les besoins sont dans [`openwiki/fr/needs-by-profile.md`](../../openwiki/fr/needs-by-profile.md).
