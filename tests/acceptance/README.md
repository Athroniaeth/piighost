# Tests d'acceptation

Les tests de ce dossier vérifient des critères des besoins par profil, par les points d'entrée publics. Chaque test porte l'identifiant `AT-<besoin>-<n>` dans sa docstring.

La liste complète, avec le statut de chaque critère, est dans le wiki : [`openwiki/tests/tests-d-acceptation.md`](../../openwiki/tests/tests-d-acceptation.md). Les besoins sont dans [`openwiki/besoins-par-profil.md`](../../openwiki/besoins-par-profil.md).
