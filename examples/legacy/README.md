# Legacy examples (v1 API)

These examples target the v1 API (`RegexDetector`, `GLiNER2Detector`,
`CompositeDetector`, the LangGraph middleware, and so on) and do not run against
the v2 rewrite yet. They are kept here for reference and will be migrated as the
v2 detectors, config, and middleware land.

For runnable v2 examples, see the PEP 723 scripts at the top of `examples/`.
